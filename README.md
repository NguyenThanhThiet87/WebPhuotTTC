# 🏍️ Adventure Gear Shop – Website Bán Đồ Phượt

Website hỗ trợ mua sắm các sản phẩm dành cho phượt thủ như mũ bảo hiểm, găng tay, balo, giáp bảo hộ và phụ kiện du lịch.
Người dùng có thể xem sản phẩm, thêm vào giỏ, đặt hàng và theo dõi trạng thái đơn. Quản trị viên quản lý sản phẩm, danh mục, khách hàng và đơn hàng.

# 🛠️ Công nghệ sử dụng
| Công nghệ            | Mô tả                         |
| -------------------- | ----------------------------- |
| ASP.NET MVC          | Backend & xử lý nghiệp vụ     |
| SQL Server           | Cơ sở dữ liệu                 |
| Entity Framework     | ORM kết nối CSDL              |
| HTML, CSS, Bootstrap | Xây dựng giao diện responsive |
| jQuery / AJAX        | Xử lý tương tác và API        |
| Visual Studio        | Môi trường phát triển         |
